# 安装与卸载

## 安装器

从官方仓库 Releases 下载 Gamma-HUD-macOS-v1.0.20.zip 或 Gamma-HUD-Windows-v1.0.20.zip，完整解压。Mac 打开“Gamma 面板安装器.app”，Windows 双击“打开安装器.cmd”。压缩包内同时提供 SHA256 校验文件。

掌机须已具备 Root/Magisk，启用 USB 调试并允许电脑授权，Root 提示允许 Shell。建议先回到主菜单、保存游戏进度，再执行安装或移除。

点击“检测设备”确认符合适配要求，再“安装面板”。桌面安装器会校验模块并尝试立即加载，无需自动重启；失败时按照日志处理，“重启并验证”为备用操作。进入内置 Nano NDS 后按 BTN_MODE 显示/隐藏。面板首次默认隐藏，请不要将没有自动显示误判为安装失败。

无法连接时检查数据线是否支持数据传输、USB 调试授权及设备 ADB 驱动。不要同时使用多个安装器或连接多个 Android 设备。

## Magisk 手动安装

已了解 Magisk 操作的用户可安装独立 GammaOS-RGDS-Performance-HUD-v1.0.11.zip。通过 Magisk 的模块页从本地安装后重启，再进入游戏按 BTN_MODE。手动 ZIP 与桌面安装器的立即加载流程不同。

## 时钟补丁

“安装补丁”只支持 SHA256 校验通过的主菜单程序，未知版本拒绝安装。空闲主菜单可立即生效；游戏或独立菜单界面运行时可能等待空闲主菜单后生效。系统更新前先“移除补丁”并核对原程序恢复状态，必要时重启后再更新系统。

## 移除与恢复

连接掌机后“移除面板”停止本工具的面板和后台监听，清理对应模块、待生效版本与运行文件，不卸载 Magisk 或其他模块。时钟补丁使用独立“移除补丁”操作。异常停止时可能保留禁用状态等待重启，请保留日志并按照提示处理。

安装器无法使用时，可通过 Magisk 禁用/移除对应模块并重启。设备异常时不要反复覆盖安装或在未备份时尝试恢复存档。

## FPS 的含义

显示下屏 DRM 翻帧完成频率，按约一秒窗口计数。重复显示相同画面仍计数，不是模拟核心运行速度。当前依赖 RG DS / Nano 的 DRM 路径；来源不明确或采样不可用显示 N/A，首次显示需等待完整采样窗口。
